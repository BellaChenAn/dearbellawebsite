# Dear Bella 简易购物页

本仓库包含一个简单的静态购物页面示例：

- 主页：index.html（展示 3 个产品）
- 产品详情页：product1.html、product2.html、product3.html
- 样式：styles.css

打开方法：在浏览器中直接打开 index.html，或者在项目根目录运行一个本地静态服务器，例如：

```bash
# 使用 Python 3 简易服务器（在 macOS / Linux / Windows 的 PowerShell 都可用）
python3 -m http.server 8000
# 然后在浏览器打开 http://localhost:8000
```
